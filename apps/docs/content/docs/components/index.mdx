Every component below ships in `@officina/ui`. Pages include a live demo and a
props table generated from the component source.

Compound components are documented on one page, not one page per part: `Card`
covers `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, and
`CardFooter`; `Table` covers its seven section and cell parts; `List`, `Form`,
`AppBar`, and `Page layout` work the same way.

## Choosing a table

Three components render tabular data, and picking the wrong one is the most
common false start:

- **[Table](/docs/components/table)** — you write the markup by hand. Right for
  small, static datasets where you want full control.
- **[DataTable](/docs/components/datatable)** — sorting, filtering, pagination,
  and selection, driven by a TanStack Table instance you own.
- **[DataGrid](/docs/components/datagrid)** — virtualized, spreadsheet-style
  grid for large datasets.

`DataTable` and `DataGrid` need `@tanstack/react-table` installed; see
[Peer dependencies](/docs/peer-dependencies).
