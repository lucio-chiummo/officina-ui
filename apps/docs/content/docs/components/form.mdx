---
title: Form
description: React Hook Form wrapper that provides form context and runs validation on submit.
---

import { FormDemo } from '@/components/demos/forms-demo';

`Form` is the canonical wrapper for every form in the library. You create a
React Hook Form instance with `useForm`, pass it as the `form` prop, and `Form`
spreads it through `FormProvider` so nested `Field` and control components can
read state and errors from context. It renders a `<form noValidate>` and wires
`onSubmit` through `form.handleSubmit`, so your handler only runs once
validation passes.

## Example

<Demo>
  <FormDemo />
</Demo>

```tsx
import { Form, Field, Input } from '@officina/ui';
import { useForm } from 'react-hook-form';

function ProfileForm() {
  const form = useForm({ defaultValues: { workspace: '' } });
  return (
    <Form form={form} onSubmit={(values) => console.log(values)}>
      <Field name="workspace" label="Workspace">
        <Input />
      </Field>
    </Form>
  );
}
```

## API

### Form

The React Hook Form wrapper.

<PropsTable name="Form" />

### FormControl

Context provider that wires a label, helper text, and error to one control via
ARIA. `Field` builds on it; use `FormControl` directly when you need a custom
arrangement.

<PropsTable name="FormControl" />

### FormLabel

Label for a `FormControl` that auto-links to its control and shows a required
indicator.

<PropsTable name="FormLabel" />

### FormHelperText

Helper/description text for a `FormControl`, linked via `aria-describedby`, with
tone options.

<PropsTable name="FormHelperText" />

### FormError

Error message for a `FormControl` that renders only while the control is marked
invalid.

<PropsTable name="FormError" />

### FormGrid

Responsive grid that arranges form fields into 1–4 columns that collapse on
small screens.

<PropsTable name="FormGrid" />
