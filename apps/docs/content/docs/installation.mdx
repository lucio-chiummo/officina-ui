## 1. Install

```bash
pnpm add @officina/ui react react-dom
```

`@officina/ui` ships ESM with bundled TypeScript types. React 19 is a required
peer dependency; a handful of components need optional peers, covered in
[Peer dependencies](/docs/peer-dependencies).

## 2. Import the stylesheets

Components carry no hardcoded colors or spacing — they read CSS custom
properties. Import both stylesheets once, at your app entry:

```ts
import '@officina/ui/tokens.css';
import '@officina/ui/styles.css';
```

<Callout type="warn">
  Order matters. `tokens.css` defines the variables that `styles.css` reads, so importing it second
  leaves components unstyled or falling back to browser defaults.
</Callout>

## 3. Render a component

```tsx
import { Button } from '@officina/ui';

export function Example() {
  return <Button variant="primary">Get started</Button>;
}
```

## Framework notes

### Next.js (App Router)

The package is compiled as a single client module — every entry ships a
`"use client"` directive — so you can import it directly from a Server
Component without wrapping it yourself.

Add it to `transpilePackages` so Next compiles the shipped JSX:

```js
// next.config.mjs
export default {
  transpilePackages: ['@officina/ui'],
};
```

Import the stylesheets in your root layout:

```tsx
// app/layout.tsx
import '@officina/ui/tokens.css';
import '@officina/ui/styles.css';
```

### Vite

No configuration needed. Import the stylesheets in `main.tsx` before your own
CSS so your overrides win:

```tsx
import '@officina/ui/tokens.css';
import '@officina/ui/styles.css';
import './index.css';
```

### Tailwind CSS

Officina UI does not require Tailwind. If your app uses it, nothing needs
wiring — the library ships its own compiled CSS and does not depend on your
Tailwind config.
